## Scope of the reported results

- Rizzo Flow probabilities are uncalibrated by default; its 49 ms measurement is for short decisions on a named GPU and quantization.
- Open-Jev and Dohnuts report accuracy on the 231 public JevBench tasks. Their numbers are not full-benchmark composite scores. Open-Jev's 27B training work is not presented as a released, evaluated checkpoint.
- OpenThai's 90.0% result is the author's 5,007-example Thai intent evaluation, not an all-task accuracy claim.
- Dohnuts code is Apache-2.0; its model weights are CC BY-NC-SA 4.0 for non-commercial research.
- djev requires the vLLM structured-diffusion PR branch described in its README.
- Laya Ultrafast changes the browser policy as well as the model. Five repeated flight searches do not establish general browser reliability.
- RoboJEV totals combine the frozen three-task and two-task campaigns: Jev 43/50, rules 48/50. The simulator pauses for API calls; video playback is not wall-clock inference speed. Per-episode metrics are public, but raw API transcripts remain private.
- Jev Chat Assistant uses Jev for judgments and ranking; a separate generative model writes reply candidates.
- jevals measures a 20-row RAG fixture. Its local Kev/Laya timing rows are estimates; large illustrative CLI output blocks are not measurements.
- jev-calibrate uses a small author-labeled support-ticket example. Tuning accuracy and held-out accuracy are reported separately.
- Laya vs Jev's two-round T-Rex result is an assisted demonstration with planner labels and safety interventions. Full recordings remain local; the repository publishes selected replay fixtures.
- JevBench's 74.4 is a four-axis composite, not 74.4% accuracy. Its adjustment of self-hosted latency is an assumption, and some benchmark tasks remain private.
- sysone-bench is included for its published evaluation, not as licensed reusable software; no repository license was found at the reviewed revision.
